# Abiprasad P P — Personal Website

Six-page responsive personal portfolio:
- Home
- About
- Skills
- Projects
- Experience
- Contact

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Before submission
1. Open `assets/js/main.js`.
2. Replace `YOUR_EMAIL@example.com` with the real professional email.
3. Replace `YOUR_LINKEDIN_URL` with the real LinkedIn profile URL.
4. If you want direct server-side form delivery instead of a mail client, connect the form to a service such as Formspree or your own backend.

The website contains responsive navigation, real portfolio content, client-side form validation, and an enquiry submission flow.
